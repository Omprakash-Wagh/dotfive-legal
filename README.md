# dotFive Legal Documents

This repository contains the official legal documentation for the **dotFive** mobile application, including the Privacy Policy, Terms of Service, and End-User License Agreement (EULA).

These documents are consolidated into a single, responsive HTML page designed to be hosted on the web and linked directly from the dotFive app.

## 📄 Contents

The `index.html` file includes three main sections:
1. **Privacy Policy**: Details regarding data collection, usage, security, and user rights.
2. **Terms of Service**: Rules of conduct, intellectual property disclaimers, and liability limitations.
3. **End-User License Agreement (EULA)**: App Store/Play Store required licensing terms, including the zero-tolerance policy for objectionable content.

## 🛠️ Modifying the Documents

To update any of the legal policies:
1. Open `index.html` in your preferred text editor.
2. Update the `Effective Date` and `Last Updated` text in the respective sections.
3. Modify the HTML content as needed within the `<section>` tags for each document.
4. Commit your changes to the `main` branch. 

## 🌐 Hosting

This repository is designed to be easily deployed to static hosting providers such as:
- GitHub Pages
- Cloudflare Pages
- Vercel
- Netlify

Simply point the hosting provider to the root directory, and the `index.html` will serve as the entry point.
